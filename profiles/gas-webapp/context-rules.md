## Context budget

- The server file and the HTML template are large and grow. **Never read either wholesale.** Use `docs/code-map.md` (generated by `/code-map`) to find the section, then read only that line range.
- Any file over 50KB is off-limits to a direct read; go through the code map or a subagent.
- Session start: `/orient`. Phase or session end: `/handoff`.

## Subagent defaults

- Searching the single-file source → an Explore subagent; take its answer, not its file dumps.
- Mechanical batch edits (renames, repeated call-site changes) → a cheaper-model subagent, one task per file region.
